# Client Onboarding Checklist

## Before Starting

Confirm:

- client name and business name
- main contact person
- project scope
- final project price
- expected timeline
- payment terms
- primary lead source
- current follow-up process
- Gmail or email workflow
- required integrations

## Access Needed

Only request access that is necessary for the project.

Possible access may include:

- lead source or form platform
- CRM
- Gmail or email account
- automation platform
- API credentials

Never ask the client to send passwords by email or chat.

Use secure access or OAuth whenever possible.

## Project Setup

Before building:

- confirm the lead source
- confirm qualification rules
- confirm follow-up goals
- confirm where drafts or outputs should go
- confirm duplicate-handling rules
- confirm who will review the final output

## Testing

Before delivery:

- test with sample leads
- verify lead routing
- verify AI-generated follow-ups
- verify Gmail draft creation
- verify duplicate protection
- confirm no unintended emails are sent
- confirm the workflow handles errors safely

## Client Review

Walk the client through:

- how leads enter the workflow
- how qualification works
- how follow-ups are generated
- where Gmail drafts appear
- how duplicate protection works
- what the client should check before sending

## Handoff

Provide:

- basic workflow documentation
- setup notes
- known limitations
- instructions for running or using the workflow
- support expectations
- next-step upgrade options

## Final Checklist

Before marking the project complete:

- client confirms the workflow works
- client understands how to use it
- payment status is confirmed
- documentation is delivered
- any follow-up work is clearly defined
