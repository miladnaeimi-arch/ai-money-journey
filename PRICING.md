# AI Sales Automation Pricing

## Starter Package

Best for small businesses that want a simple AI lead follow-up workflow.

Includes:

- lead qualification setup

- HIGH / MEDIUM / LOW routing

- personalized AI follow-up drafts

- Gmail draft creation

- duplicate protection

- setup and testing

- basic documentation

Suggested starting price:

$500 - $1,000

## Growth Package

Best for businesses that need a more customized lead automation workflow.

Includes everything in the Starter Package, plus:

- customized lead qualification logic

- integration with an additional lead source

- customized follow-up rules

- workflow adjustments for the client's sales process

- additional testing and implementation support

Suggested starting price:

$1,500 - $3,000
